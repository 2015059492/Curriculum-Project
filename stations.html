Immune System Learning Stations

Learners move through five makerspace-inspired stations. Each station supports exploration, interaction, creation, application, and reflection.

Station 1: Explore Zone

View diagrams, posters, and short videos to activate prior knowledge about immunity.

Start Explore Activity

Station 2: Game & Simulation Zone

Use games and simulations to observe how the immune system responds to pathogens.

Start Simulation

Station 3: Build Zone

Construct a physical or digital model showing interactions between pathogens, antibodies, and immune cells.

Start Build Activity

Station 4: Apply Zone

Analyze real-world scenarios involving infections, vaccination, antibiotics, and immune responses.

Start Application Task

Station 5: AI & Reflection Zone

Use AI-supported tools to generate explanations, compare answers, and reflect on learning.

Start Reflection
